# Screenshots

This folder contains UI screenshots of the DarkMap application.

## How to Add Screenshots

1. Run the application locally (see [Installation Guide](../../docs/INSTALLATION.md))
2. Navigate to the pages you want to capture
3. Take a screenshot and save it here using a descriptive filename

## Recommended Screenshots

| Filename | Page | Description |
|---|---|---|
| `landing-page.png` | `/` | Hero screen with the DarkMap tagline |
| `india-map-full.png` | `/map` | Full map view with all markers visible |
| `filter-high-severity.png` | `/map` | Map filtered to high-severity incidents only |
| `filter-by-category.png` | `/map` | Map filtered by a specific crime category |
| `dashboard-cards.png` | `/map` | Close-up of the stats dashboard cards |
| `marker-popup.png` | `/map` | A marker clicked to show incident details |

## Naming Convention

Use lowercase with hyphens: `page-description-state.png`
